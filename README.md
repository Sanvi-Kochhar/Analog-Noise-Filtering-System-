This project demonstrates an analog noise filtering system implemented using an op-amp based active low-pass filter. 
The circuit uses an LM358 op-amp along with an RC (resistor-capacitor) network to attenuate high-frequency noise while allowing low-frequency signals to pass. 
The goal is to improve signal quality by smoothing unwanted high-frequency components, making it suitable for applications such as audio processing and sensor signal conditioning. 
The system was built on a breadboard and tested using audio input signals, with performance verified by observing smoother output behavior and further validated through LTspice simulation.
LM358 op-amp is used as the core amplification element. Resistors and capacitors form the RC network that determines the cutoff frequency. Additional components include a breadboard, jumper wires, and an audio input source.
The circuit is based on an RC low-pass filter combined with an op-amp. Low-frequency signals are allowed to pass, while high-frequency components are attenuated. The op-amp amplifies the filtered output signal. The cutoff frequency is determined by the values of the resistor and capacitor.
The design is simple and cost-effective. It effectively reduces high-frequency noise. It provides improved signal quality using active filtering.
The circuit can be used in audio signal processing. It is useful for sensor signal conditioning. It can also be applied in embedded and industrial systems where noise reduction is required.
